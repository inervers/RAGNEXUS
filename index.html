RAGNEXUS · PRODUCTION RAG SERVICE

生产级 RAG 服务，
混合检索 × Multi-Agent 编排

集成 Hybrid Search（稠密向量 + BM25 + RRF 融合）、Cross-Encoder Reranker 精排、Multi-Agent 写作流水线。终端风格 React 前端（4-tab），Docker 一键部署。

Python 3.11 FastAPI ChromaDB Sentence-Transformers BM25 Cross-Encoder React TypeScript Vite nginx Docker

01核心链路

从原始文档到流式回答，一条完整的检索增强生成管线。

STAGE 01
Ingest 入库
txt / PDF / OCR 解析，去重、分块
STAGE 02
Embedding
all-MiniLM-L6-v2 向量化
STAGE 03
ChromaDB
嵌入式向量库，检索 < 50ms
STAGE 04
混合检索
稠密 + BM25 + RRF 融合
STAGE 05
Reranker
Cross-Encoder 二次精排
STAGE 06
LLM 回答
强制检索注入 + SSE 流式输出

02功能模块

功能说明
标准 RAG 问答 Function Calling 驱动，自动检索知识库 + LLM 回答，SSE 流式 + 打字动画 + 取消
混合检索 稠密向量 + BM25 稀疏检索 + RRF 融合，同时覆盖语义相关与精确术语匹配
Reranker 精排 Cross-Encoder 对粗筛结果重排序，修正 Bi-Encoder 的排序偏差
Multi-Agent 写作 研究员 → 写作者 → 审核员协作流水线，带持久化记忆与评分 / 重试循环
知识库管理 txt / PDF 拖拽上传，PDF 实时预览，按文档分组浏览与删除

能力实现

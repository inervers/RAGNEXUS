RagNexus
概览 快速开始 API 设计取舍
QUICKSTART

5 分钟跑起来

本地开发（两个终端）或 Docker 一键部署，任选一条路径。

01前置要求

Python 3.11+
后端 FastAPI 服务
Node.js 20+
前端 Vite dev / 构建
Docker（可选）
仅容器部署需要

02环境变量

在项目根目录创建 .env：

变量说明默认值
DEEPSEEK_API_KEYDeepSeek API Key必填
ZHIPU_API_KEY智谱 API Key（fallback）可选
LLM_BASE_URL覆盖 LLM 端点按 key 自动选
LLM_MODEL覆盖模型名deepseek-v4-flash
RAG_API_KEYAPI 鉴权密钥rag-secret-key-2024
RAG_RATE_LIMIT每分钟最大请求数30

03本地运行

终端一：启动 API 服务（默认 8000 端口）

python rag_api.py

终端二：启动前端 dev server（默认 5173 端口）

cd frontend
npm install
npm run dev

浏览器打开 http://localhost:5173（vite dev 已配置代理转发到 8000）。

04Docker 部署

国内网络：先手动拉基础镜像（BuildKit 的 FROM 不继承 pull 代理）。
docker pull node:20-alpine
docker pull nginx:alpine
docker compose up -d --build
服务地址
前端http://localhost:8080（nginx 托管，同源请求转发到 API）
APIhttp://localhost:8000

前端 API 走同源（API_BASE=""），由 nginx 正则转发 /health|/query|/doc|/kb|/agent，无需跨域配置。

Agent 的写作记忆保存在本地 memory/ 目录，容器重建后记忆不丢失。

05验证

流式问答（PowerShell 用单引号包 JSON）

curl.exe -N -X POST http://localhost:8000/query/stream ^
  -H "Content-Type: application/json" ^
  -H "X-API-Key: rag-secret-key-2024" ^
  -d '{"question":"什么是RAG"}'

混合检索（稠密 + BM25 + Reranker）

curl.exe -X POST http://localhost:8000/query/hybrid ^
  -H "Content-Type: application/json" ^
  -H "X-API-Key: rag-secret-key-2024" ^
  -d '{"question":"What is PyTorch?","use_reranker":true}'

06排障

镜像构建崩溃、npm 安装失败、后端连接异常等全套踩坑经验见仓库内 docs/OPS-NOTES.md（运维笔记）。

API REFERENCE

HTTP API

除健康检查外所有接口均需 X-API-Key 请求头鉴权（默认 rag-secret-key-2024），无 Key 返回 401，超限返回 429。

01接口一览

接口鉴权说明
GET /health免鉴权健康检查
POST /queryX-API-Key标准 RAG 问答
POST /query/streamX-API-Key流式问答（SSE：tool / token / done 事件）
POST /query/hybridX-API-Key混合检索，可选 Reranker
POST /docX-API-Key添加知识（title + content，无字符数限制）
GET /kb/docsX-API-Key获取知识库全部文档（records：id / source / document）
POST /kb/docs/deleteX-API-Key按 id 批量删除文档
POST /doc/previewX-API-Key文档预览（filename + base64 → 文本前 5000 字符）
POST /agent/writeX-API-KeyMulti-Agent 写作流水线

02示例

流式问答

curl.exe -N -X POST http://localhost:8000/query/stream ^
  -H "Content-Type: application/json" ^
  -H "X-API-Key: rag-secret-key-2024" ^
  -d '{"question":"什么是RAG"}'

SSE 事件流：tool（工具调用结果）→ token（增量 token）→ done（结束）。

混合检索

curl.exe -X POST http://localhost:8000/query/hybrid ^
  -H "Content-Type: application/json" ^
  -H "X-API-Key: rag-secret-key-2024" ^
  -d '{"question":"What is PyTorch?","use_reranker":true}'

Multi-Agent 写作

curl.exe -X POST http://localhost:8000/agent/write ^
  -H "Content-Type: application/json" ^
  -H "X-API-Key: rag-secret-key-2024" ^
  -d '{"topic":"PyTorch 动态计算图","max_retries":2}'

添加文档

curl.exe -X POST http://localhost:8000/doc ^
  -H "Content-Type: application/json" ^
  -H "X-API-Key: rag-secret-key-2024" ^
  -d '{"title":"RAG 入门","content":"检索增强生成（RAG）..."}'

删除文档（按 id 批量）

curl.exe -X POST http://localhost:8000/kb/docs/delete ^
  -H "Content-Type: application/json" ^
  -H "X-API-Key: rag-secret-key-2024" ^
  -d '{"ids":["chunk-id-1","chunk-id-2"]}'

返回 {"deleted": [...], "missing": [...], "remaining": N}。

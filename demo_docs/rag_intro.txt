RAG（检索增强生成）是目前大模型落地的核心范式。它的基本流程是：用户提问 → 从知识库检索相关文档 → 将文档作为上下文拼入 prompt → LLM 基于上下文生成答案。

RAG 解决了 LLM 的两个根本问题：一是知识截止日期问题，模型训练完成后无法获取新知识；二是幻觉问题，模型可能编造不存在的细节。通过检索真实文档作为依据，RAG 大大降低了幻觉率。

一个生产级 RAG 系统包含以下组件：
- 文档解析层：支持 PDF、TXT、Markdown 等格式
- 文档分割器：将长文档切分成语义完整的块（chunk），常用 256-512 token
- 嵌入模型：将文本转为向量，如 all-MiniLM-L6-v2
- 向量数据库：存储和检索向量，如 ChromaDB
- 检索器：执行向量相似度搜索
- 生成模型：基于检索结果生成最终答案

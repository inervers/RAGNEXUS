Docker 容器化是 AI 服务生产部署的标准方式。通过将应用及其依赖打包成镜像，确保开发、测试、生产环境一致，消除"在我电脑上能跑"的问题。

Dockerfile 的层缓存优化直接影响构建效率。关键原则：将变化频率低的层放在前面。典型的分层策略：
- 第 1 层：基础镜像（Python 3.11-slim）
- 第 2 层：重量级依赖（PyTorch、ChromaDB）
- 第 3 层：应用依赖（FastAPI、Streamlit）
- 第 4 层：应用代码

Docker Compose 是编排多容器应用的工具。使用 docker-compose.yml 定义服务、网络、卷挂载，一键启动整个系统。bind mount 用于将主机的模型缓存和日志目录映射到容器内，named volume 用于持久化数据库数据。

镜像体积是 Docker 部署的常见痛点。PyTorch CUDA 版约 3.5GB，ChromaDB 内置 ONNX Runtime 约 1.5GB。使用 CPU-only PyTorch 可将镜像从 9GB 压缩到约 3-4GB。
